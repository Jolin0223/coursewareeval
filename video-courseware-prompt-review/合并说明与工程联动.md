## 两个不能用提示词假装完成的工程联动

### 自动连续播放

目标仍是首次进入后相邻视频自动播放，不让老师每段点。**本包未达成这一项**，因为开发M1要求当前pointerup/键盘激活并明确禁止ended、加载或计时器回调触发play/playMedia；唯一自动入口是教师工具首镜头。与用户锁定播放修复的最新要求相比，本次优先保护修复，不加入互相冲突的正文。

开发下一步需要在当前playMedia基础上提供可验证、可取消的连续播放能力，而非让生成器绕过它。能力应识别“教师已启动的连续序列”，允许自然ended进入下一镜头；手动暂停、必做H5、明确教学停顿、切场和预览边界取消旧推进；错误仍保留画面与边缘恢复入口；静态video/资源回填/包内路径保持。真实实现和跨端回归完成后，再同步P5/P6/P7/R1共用M1及其正文。本次不提供猜测API或未经实现的替换M1。

### 教师工具面板及字幕设置

开发当前规则明确“左下角可拖动入口，展开仅场景列表”。[钉钉规格](https://alidocs.dingtalk.com/i/nodes/20eMKjyp81RNZrrdfZv55j30WxAZB1Gv?corpId=)的目标为左侧居中，展开宽高各约50%（面积1/4）、固定标题/关闭区、双列带序号目录、当前项滚动到可见、随教学语言显示iTeacher Tools/教师工具。选择产品目标更适合课堂，但结构要由开发修改固定运行时；本轮提示词不授权模型覆盖它。

入口字号/热区按实际大屏与小预览核验，不能仅按逻辑像素把入口缩得很小；同时不把入口放大为画布1/4。不允许工具挤压教学画布。保留任意进度跳场、不算完成/奖励、停止旧场媒体与异步行为的规则；单场预览保持范围隔离。

字幕“按教学默认／显示／隐藏”建议放教师工具，但当前只有场景目录。开发需明确字幕数据可用性、当前显示状态、开关通知课件、切场同步与预览行为后再接入。不让生成器猜方法、写进shadowRoot或另造第二套教师工具。

## 暂停与小学三科字幕建议

**暂停/继续放在视频边缘，教师工具里可以扩展更多设置。** 暂停保留时间和画面，继续通过playMedia且restart=false；不重新归零。正常播放无中央遮挡。开关面板和加载就绪不得覆盖手动暂停。控件使用主题图标+短文案，保留键盘与触屏操作。

**字幕不全开也不全关，按学习任务设默认。** 这是本轮产品建议，尚未宣称平台支持。

| 场景 | 默认文字策略 |
| --- | --- |
| 语文朗读、识字示范 | 显示当前对应字词句，帮助音形对应 |
| 语文故事听赏、复述准备 | 不叠全文，先听和看，回顾时可显示 |
| 数学演示 | 保留数量、单位、条件、关系；少用重复整段旁白字幕 |
| 英语示范、跟读、复习 | 显示对应英语原文，不默认加中文翻译 |
| 英语听辨、听力作答 | 默认隐藏可能提供答案的转写，讲解/辅助时教师可显示 |

核心教学文字不归字幕开关控制：汉字/拼音示范、算式、数量、图形标签、题干不能一关全没。可选字幕要独立层、真实逐镜头时间轴、跟随媒体时间；不烧入视频，通常一到两行，不遮口型/过程/题目。只有文稿可展示“讲解文本”，不能平均分配时长伪造同步。教师主动覆盖应保留同次会话选择，听力任务提示文字可能提供答案线索。

这是基于任务目标的取舍，不是“所有小学生字幕都更好/更差”的定论。多媒体设计指导提醒避免无必要的重复文字，也保留语言学习差异；因此采用可切换、按任务默认的方案。[ACU多媒体设计原则](https://staff.acu.edu.au/our_university/centre-for-education-and-innovation/educational-technologies/creating-video-resources/multimedia-design-principles)

## 旧故障证据如何处理

此前小熊HTML确认过未请求第二段播放、7:4视频与16:9舞台不一致、教师工具固定Shadow DOM。它是旧snapshot证据，**不代表开发最新修复后的代码**。用户已确认“点播放无效”由开发修好，本次不再要求按旧snapshot重写播放机制，也不沿用之前建议的click或safeResetMedia方案。

[HTML输出缺失会话](https://box.test.xdf.cn/kpm/891740c5e9804c1ebebfae2fee5dd350)由开发查失败stage、原始响应、finish reason、流式聚合和提取前后长度；没有日志不判定token超限。完整HTML输出、去冗余与禁止占位规则已保留，不能承诺仅换提示词必修该故障。

开发P4固定追加约束有一句将durationSeconds与引用数量上限相比较，量纲有歧义。本包按“保留开发独立内容”保留原文，并在清单提醒开发将时长范围与引用数量分别表述；未静默改代码固定约束。
