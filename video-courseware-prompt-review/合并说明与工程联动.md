# r9效果修订与工程联动

12项证据来自11月16日产品验收记录及用户截图。未获取这批会话最终HTML、实际媒体、错误日志和实发提示词，因此下述为约束与排查方向，不是根因结论。周五失败已修复是用户与开发反馈；VIT-047是今日独立的新失败，不能混为一个故障。

## 1. 教师工具：运行时统一落实

当前M1及P5–P7/R1要求固定教师工具由宿主管理，只允许生成代码配置8个主题变量。因此本轮不让AI自己新建更大的菜单。

开发对照已确认教师工具规格扩大入口与目录（既有规范为面板宽高各约舞台50%、两列目录，并限制在实际视口内），列表展示“序号＋场景名”，序号由确认场景的真实教学顺序产生，当前场景高亮。不要让P4将序号硬写进name导致重复编号。大小屏实测可辨认、可触控，拖动不误切场；单场预览保持原隔离边界，不通过开放跨场目录实现。

## 2. 自然连播：与当前M1存在明确冲突

最新开发文档M1第4、5条仍禁止ended/定时器发起播放，mixed场景先H5后视频仍需可见按钮。P5/P6/P7/R1也保留相同要求。本包逐字保留这些规则，所以**尚不能达成VIT-043**。不是再加一条自动播放文案即可解决。

目标行为供开发做受控升级：

| 触发 | 目标行为 |
| --- | --- |
| 首次有效点击整图封面 | 进入一次并请求首段播放，不叠加中央播放按钮 |
| 同场或跨场视频结束，后面仍是视频 | 当前播放会话有效且未主动暂停时请求下一段；可呈现前保留有效画面 |
| 视频结束，后面是H5 | 显示真实任务，等待操作，不加二次开始门槛 |
| H5达到真实完成条件、必要反馈结束 | 继续后续教学；后续是视频则请求播放，不以任意点击/计时器冒充作答完成 |
| 用户主动暂停 | 保留帧与进度；加载完成及迟到回调不自动恢复 |
| 教师跳转／离场 | 清理旧媒体和旧回调，尊重当前暂停意图与目标场景 |
| 单场景预览 | 允许本场内部衔接，不自动越到其他场景 |
| 真实播放拒绝／资源失败 | 保留画面并提供明确继续／重试；不无限重试，不吞错 |

联动顺序：先确认宿主支持的受控续播入口和状态，再同步M1、P5/P6/P7/R1以及程序检查器，最后在真实预览和目标浏览器验证。保留开发已修复的媒体地址、手势首播、重播和异步清理实现；不要为连播重写整套播放器。本包没有添加假想API、打开autoplay属性或直接在ended调用play。

## 3. 素材效果不能由HTML代修

- 抠图：检查生产要求、透明化是否执行、最终引用是否为处理后版本。Alpha检查加浅/深背景合成查看，不能只检查扩展名或存在透明像素。不要把透明化预览中的棋盘格烘焙进交付图。
- 黑边：分别定位源片内黑边、容器尺寸、默认边距和二次缩放。16:9舞台内部不留非设计黑边；非16:9外部视口允许主题色余区，不拉伸、不裁掉教学信息。
- 旁白口型：核对speaker/audio/dub与实际发给视频模型的pictureDescription。旁白段明确无说话口型，参考图与动作一致；输出仍串口型时用可支持的镜头替代或媒体重制。没有后期配音能力时不把“后混旁白”写成已可执行步骤。

## 4. 播放无响应与生成失败的最小排查材料

VIT-037、044、046分别保存原会话，不能因其中一个通过就关闭另外两个。取最终HTML及目标资源响应，核对点击是否到达、遮罩是否拦截、playMedia返回结果、media.error、场景/镜头标记与退出清理。已有代码修复继续保留，不用截图猜根因。

VIT-047需要：失败阶段及规则ID、errorCode/errorMessage、模型原始响应及finish_reason、响应提取前后长度、实际SystemMessage版本、配置覆盖来源、程序检查报告。若与素材有关，再补当前模型能力和真实媒体属性。检查§4.6模板字面转义和目录展开是否实际生效；不要手工替换花括号、放宽结构检查或盲目重试付费任务。
