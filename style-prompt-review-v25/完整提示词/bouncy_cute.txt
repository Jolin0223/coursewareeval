0. 原课件保留规则
显示适配：保留原题目的顺序、分组、对应关系和操作流程，不把源坐标数值机械套进尺寸已改变的新题板。按实际父容器的内容宽高排布全部对象，确保末项及每个对象的完整边界都在可用区域内；空间不足时先压缩非教学装饰与间距，再局部调整卡片和题板尺寸，保持清楚可辨。拖拽位移、碰撞检测、回弹和吸附使用一致的坐标换算。不得靠裁切、隐藏对象、删减数量或让核心任务横向滚动解决越界；原教学必要的遮挡与拼合关系保留。
通用运行保护：适用于所有基础风格。保留原课件已验证的初始化、事件绑定、答案映射、教学音频、SDK上报和坐标关系，只做封面接入与视觉适配所需的局部改动；不得引入未定义变量、重复绑定、坐标错位或错误命中。除原教学需要的叠放、遮挡、拼合和连线外，不得新增使操作对象难以识别或无法命中的重叠、出界与遮挡。源课件已有阻断问题时单列原缺陷，必要修复另行记录，不通过改题或删内容掩盖。
本风格用于 UI 视觉换肤，可按第2节新增或替换封面；进入教学后不得改变原课件的学科、题型、题目内容、答案、素材数量、槽位数量、组件数量、教学布局关系、按钮功能、计分逻辑和交互流程。原来是英语看图拼词、填空、拖拽、选择、分类、连线、逻辑推理或其他玩法，换风格后仍保持原玩法和原题目结构。主互动题页中的题干、选项、答案、字母、汉字、拼音、数字、公式、倒计时、得分、按钮文案、反馈文案和关卡信息等可变教学内容，必须由 HTML/CSS/JS 渲染，不要烘焙进背景图或题板底图。

1. 整体视觉与布局
风格识别锚点：第一眼应像软萌童话宇宙和果冻闯关 UI。使用圆润蛋形角色、大眼睛、无硬棱角、暖色高饱和糖果色、软云、彩虹桥、圆润山丘、糖果屋、甜甜圈道具、糖果渐变大圆角按钮和白描边；动效观感要像果冻 Q 弹，明亮、弹跳、轻竞技。
采用软萌童话宇宙和果冻 Q 弹 UI。画面可以有圆润蛋形角色、大眼睛、软云、彩虹桥、圆润山丘、糖果屋、甜甜圈和软糖道具。整体明亮、高饱和、圆润、有弹性，不能变成暗黑科技、硬质金属或普通卡片风。
使用横版课件画布，画布主体集中在中央学习区，四周保留安全边距。顶部保留原课件已有标题、关卡、进度、奖励、倒计时或得分信息；中央按原课件布局放置题目、图片区、网格、线索、选项、素材池、槽位或操作区；底部或右侧保留原有按钮和工具按钮。背景只提供氛围，不承担学习信息。

2. 封面图规范与生图提示词逻辑
【本节适用范围】第2节是完整封面设计，第3节是进入后的主互动页背景，两者必须分别生成、分别使用。封面继续执行本节第3项的原有美术描述，包括艺术字、角色、场景、材质、副标题载体和按钮设计；不得把它改成“空背景＋普通HTML标题按钮”。第3节的无文字、无按钮、中央留白要求，以及第4—6节的题板、标准正文字体、学习区低干扰规则，只约束主互动页，不得用来删减封面。选择基础风格时，默认生成或替换一张完整设计封面，源课件没有封面也默认添加；只有老师明确要求“不要封面”“直接进入题目”或“去掉封面”时才省略。不能仅凭源文件没有封面推断老师不需要。仅叠加质感时不新增封面或其他页面，保持原页面结构。

1）封面图用于儿童互动课件首页。封面图本身必须生成主标题、副标题和进入按钮；副标题不得超过15个字，图上不生成任何额外文字、包括风格名、品牌名、logo、水印、二维码、角标、色值、尺寸标记、伪文字或无关宣传语都不允许生成。封面图中的主标题、副标题、按钮造型和按钮文字是最终可见内容，必须保留。HTML 不得在这张封面图上再次叠加可见标题、副标题、按钮、按钮文字或底座；只配置覆盖封面的透明点击层，点击封面任意位置进入原课件。这里禁止的是 HTML 重复叠加，不是禁止图片生成标题或按钮。
2）主标题、副标题和按钮文案都是可变元素，必须根据当前课件真实内容替换；若为英语课件则尽量用英文，若非英语课件则一律用中文。标题、短副标题和进入按钮需要沿同一视觉主轴组织，层级清楚、可读性强，适合课堂投屏。
3）本视觉风格封面的生图提示词：
软萌童话宇宙儿童封面，暖色调高饱和糖果色，云端彩虹桥、圆润山丘、糖果屋、甜甜圈、星星和果冻角色。画面两侧放圆润蛋形角色、大眼睛、无硬棱角，像会弹跳的果冻伙伴。中心上方生成粉紫色果冻质感大标题“{标题内容根据课件真实内容填充，若为英语课件则尽量用英文，若非英文课件则一律用中文}”，标题Q弹、厚白描边、带糖霜高光和小星星。标题下方生成短副标题“{副标题内容根据课件真实内容填充，副标题不超过15个字，若为英语课件则尽量用英文，若非英文课件则一律用中文}”。中下方生成黄色或粉色果冻胶囊按钮，按钮文字为“{进入游戏，按钮内容根据课件真实内容填充，若为英语课件则尽量用英文，若非英文课件则一律用中文}”，按钮带白描边和Q弹高光。

4）封面接入顺序：先根据真实课件确认主标题、短副标题和进入文案，再依照上面的原版美术描述生成一张完整封面图；将它完整适配课件舞台，不裁掉文字、角色或按钮，也不把整张封面当作中间的小插图套进另一张封面。仅在封面容器内移除或隐藏源 HTML 的标题、副标题、示例插画和可见开始按钮，清理伪元素及 CSS 背景中重复的文字/按钮；主互动页的题干、选项、答案、控件和逻辑全部保留。不要因源课件原来使用 HTML 标题而继续保留第二套可见封面。
5）透明点击层只承接进入事件，不绘制文字、图标、背景、边框、阴影或底座；可保留不可见的无障碍名称和键盘进入能力，不能将整张封面图设成透明。一次完整点击/触控只进入一次，不在 pointerdown 时提前撤掉封面；隔离本次手势，禁止继续触发下一页答案、拖拽或提交。进入第一题时仍为未作答状态。封面显示期间可预加载资源，但教学计时、题目朗读和SDK开始上报应在进入教学后沿原启动逻辑执行一次；进入封面的手势不计入作答或重试。
6）交付前同时核对封面原图与浏览器实际首屏：图中艺术标题、短副标题和设计按钮齐全且各一套，浏览器没有额外的可见 DOM/CSS 文字或按钮，点击任意位置可进入第一题。若有重复，修正 HTML 接入层；若图中文字错误，单独修正封面素材。不得用删掉艺术字、角色、按钮设计，换成空场景，或直接跳过封面的办法通过去重检查。

3. 背景图规范与生图提示词逻辑
素材分工：先识别本页答题、计数、匹配和操作目标，再将图片分为“背景”“承载物”“独立教学对象”。背景不得包含目标及容易被误认成目标的同类物、文字或操作外观；承载物只画原有容器本身，原为空的篮子、框、托盘不预装目标，也不把题目对象画进承载物；独立教学对象按原身份、数量、分组与状态保留。原任务必需的参照、干扰选项、遮挡与拼合关系仍保留，不按装饰误删。所有风格装饰候选均受此约束，材质不改变答题线索与关键几何关系；本条只约束内页，不删减第2节的封面美术。
实际调用要求：把本页目标、易混淆同类、素材角色、允许场景和应排除内容，解析成每张图片的最终生图提示词。先从第1节和本节的风格候选元素中删除冲突项，再调用生图；不得把“按任务过滤”或未填写的占位符连同被禁止物品的正向描述原样下传。页面容器或背景被重做时，重新核对全部已有教学对象仍可见、可操作。
1）背景图只用于提供风格氛围，不强行生成题目承载区域。题目白板、任务板、卡片、槽位、按钮和状态栏应由 HTML/CSS/JS 根据当前课件内容绘制，并覆盖在背景图上。背景图中不要生成框、白板、题板、任务板、玻璃板、卡片、按钮、标题、题目文字、选项文字、数字、字母、汉字、格线、槽位、logo、水印或二维码。
2）背景只承担场景氛围和视觉风格统一，不承载题目、答案、玩法说明、按钮引导或知识示例。生成16:9横向全幅场景底图，场景自然延展至画面四边，仅用环境、柔和光线和配色营造主题氛围，不照搬封面构图与装饰密度。
根据当前教学布局，所有叠加题干、卡片、选项、操作对象和按钮的位置保持连续、低细节、低对比、空间由天空、墙面、地面等自然形成，不用边框、面板、卡片、独立色块或分割线划出承载区域。边缘同样保持低干扰，装饰元素少而小，仅在少数角落远景点缀；降低饱和度、对比度与细节，不用大型近景角色、道具、强光、高光、密集纹理或强透视道路吸引视线。画面不包含文字字符、色值色卡、题目答案、可能被误认为题目或选项的知识点对象、界面控件或可点物的中大主体。若主题物本身与本页答题目标冲突，省略该物，用主题配色、光照与材质维持风格。
本条只约束教学页背景；当前任务必需的参照物、真实教学对象、承载物和干扰选项按素材分工独立保留，不因背景简化删除题目内容。第1、5节列举的主题物不构成背景必画清单，和本条冲突时从实际生图提示词中移除；HTML题板按原教学布局绘制，不因背景无框而删除。
3）本视觉风格背景图的生图提示词：
柔和粉紫与浅蓝，圆润Q弹材质气质。将上述背景规则、本页需留空的实际区域和需排除的教学目标具体写入最终图片提示词；不含未填写占位符或冲突的正向装饰清单。
4. 按钮、字体与触控规范
功能按钮尺寸保护（教学页）：风格调整前识别全部原有功能按钮，记录容器、可见图标、文案、点击热区和功能。原按钮已清楚可用时，不因换肤缩小其容器、可见图标或热区；优先只改配色、材质与边框。下列尺寸以1920×1080逻辑画布为基准，画布整体等比缩放一次；其他逻辑画布按相同比例换算，禁止已缩放父容器内再次按视口缩小按钮。
返回、首页、声音、静音、关闭等常用图标按钮使用96×96px容器，图标48—78px；播放、暂停等核心操作使用112×112px容器，图标52—84px；重试、下一步等结果操作使用标准图标加短文案，宽220—280px、高88—96px，图标40—48px；其他功能图标按钮不小于88×88px。尺寸指实际可点击区域，同时可见容器、图标和文字须清楚可辨，不能仅扩大透明热区而保留微小图标。按钮距离画布边缘不少于40px，相邻功能按钮间距不少于24px，均按同一比例换算。同层级按钮统一尺寸、圆角、描边和图标比例，图标居中并留白，不用夸张异形外框。
原本更大且不遮挡内容的按钮继续保留，不为套规范强行缩小。功能按钮与题目选项、教学图片、拖拽块、槽位分开处理，不能把功能按钮尺寸机械套到所有教学对象。空间不足先减非教学装饰和无效留白，再调整功能区布局，不缩小教学内容、裁切对象或让热区相互覆盖；保留原事件、禁用态、反馈和可访问名称。交付时对照换肤前后逐个核对按钮可见大小、热区、间距与实际操作。封面仍沿第2节使用完整设计图与透明进入层，不增加第二套可见按钮。
功能图标验收：只针对独立的播放、重置等功能图标位，按图片实际可见符号检查，透明留白、外框与阴影不计入主体。核心符号最长边占图标位短边的60%—80%，使用不透明、与底色清楚区分的实色；不能只扩大外框或图片CSS盒子。优先安全去除原功能图标的无意义留白；无法安全处理时，使用语义一致的清楚符号替换其外观，保留原事件、静音逻辑和热区。完整教学图片仅按比例适配，不为凑占比裁切对象；独立小图标位规则不得套用于题目插图。
教学可读性：题干、选项文字、比较符号、数量标记和关键线条使用不透明实色，不使用透明渐变填字、浅色描边字或发光代替字形。复杂背景后为对应文字或控件加局部纯色底，不透明度不随主题降低；保留颜色作为答案线索时的原语义，不强制把所有题目改成同一颜色。玻璃、糖果和科技光效只用于学习区域之外的装饰或控件外缘，不穿过文字、线段、槽位和功能符号。
按钮使用果冻、软糖、云朵或弹力胶囊按钮，白描边、柔和高光、轻微上浮和按压回弹明显。字体圆润饱满，不能过细。
本课件面向小学低中高年级儿童，所有核心文字和可点击区域必须适合课堂投屏、互动屏和平板触控。题干、核心选项、按钮文字和状态数字要使用明显偏大的字号，普通提示文字也要清楚可读；主按钮、选项卡、拖拽块和槽位要有足够大的触碰面积和间距，儿童手指点击不容易误触。按钮必须有清楚边界、高对比文字、按压反馈和禁用态；不要把关键文字做得过小、过细、过浅或压在复杂纹理上。

5. 色彩、材质与装饰密度
色彩以高明度糖果色、樱花粉、天空蓝、薄荷绿、柠檬黄、薰衣草紫、奶油白和柔和红为主。
色彩只作为视觉方向，不在图片中显示任何色号、色卡编号、代码、CSS 文本或设计参数。整体保持明亮、干净、护眼，避免大面积深色、强霓虹、复杂渐变和高压迫背景。装饰密度必须低于学习内容，角色、花草、糖果、气泡、电话线、科技光线或海图道具只放在边缘、角落或低层背景，不得穿过题目、选项、槽位、网格、按钮和反馈区域。

6. UI层级与反馈
页面状态：封面只在封面状态显示并接收输入。进入教学时，明确将封面容器设为display:none并关闭指针命中；进入封面时再按原流程恢复显示。检查最终计算样式，不得让ID选择器或!important覆盖隐藏规则。若实际结构使用#cover-page和active类，可在现有样式之后使用：
#cover-page:not(.active) { display: none; pointer-events: none; }
#cover-page.active { display: flex; }
以上选择器只在实际ID和状态类匹配时使用；其他结构按实际容器和页面状态实现等价规则。教学页使用自己的背景，不复用封面图，不继承封面的标题或开始按钮。进入、完成与重置后核对：封面关闭时计算样式确为display:none、不可命中，教学页和原交互正常；如果原流程返回封面，再恢复封面显示。此规则只修显示状态，不修改第2节的封面美术内容。
底层是风格化背景，只提供氛围；中层是主主题板和内部功能卡片，盖在背景图上，由html/CSS/JS 绘制适合本风格的题板区域，是最高信息承载层；上层是可拖拽对象、选项、按钮、反馈条和当前选中态；弹窗层用于结果、时间到或完成反馈，必须有遮罩或清楚的独立卡片，不能遮挡关键学习内容。
正确反馈使用果冻弹起、彩纸、星光和绿色描边；错误反馈使用柔软回弹和浅红边框；选中态使用 Q 弹上浮和白描边。
所有反馈只强化原交互，不新增新玩法，不改变原题目判断逻辑。
