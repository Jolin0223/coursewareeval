0. 原课件保留规则

本节涉及按钮材质与主题物仅作为配色、圆角、描边、轻阴影的风格参考；教学页功能按钮具体实现以第4节CSS标准控件为准，不把功能按钮做成主题道具图片。
风格识别锚点：第一眼应像儿童逻辑训练营，而不是商务网格或抽象设计稿。使用清爽青蓝渐变背景、淡米白棋盘或宫格底纹、中央清晰逻辑题互动区、白色圆角卡片、浅灰分隔线、暖黄色圆角外框、亮蓝主按钮、暖橙答案高亮和绿色正确反馈；适合数独、迷宫、行列推理和逻辑挑战，整体干净、专注、儿童友好。

使用横版课件画布。最底层是蓝天到浅青蓝的渐变背景，可有淡淡云朵、树叶、纸飞机、小圆点和角落植物，但背景只提供轻松氛围，不承担学习信息。主学习区放在中央大型奶油白题板内，题板四周是柔和黄橙厚边框，整体像儿童训练营任务板。顶部可有返回按钮、课程标题、关卡胶囊、星星数量、计时器等状态区；中间是核心题目与操作区；左右可放规则、角色提示、工具按钮和反馈卡。所有正式文字和状态数据由页面渲染。

1）封面图用于儿童互动课件首页。封面图本身必须生成主标题、副标题和进入按钮；副标题不得超过15个字，图上不生成任何额外文字、包括风格名、品牌名、logo、水印、二维码、角标、色值、尺寸标记、伪文字或无关宣传语都不允许生成。封面图中的主标题、副标题、按钮造型和按钮文字是最终可见内容，必须保留。HTML 不得在这张封面图上再次叠加可见标题、副标题、按钮、按钮文字或底座；只配置覆盖封面的透明点击层，点击封面任意位置进入原课件。这里禁止的是 HTML 重复叠加，不是禁止图片生成标题或按钮。
2）主标题、副标题和按钮文案都是可变元素，必须根据当前课件真实内容替换；若为英语课件则尽量用英文，若非英语课件则一律用中文。标题、短副标题和进入按钮需要沿同一视觉主轴组织，层级清楚、可读性强，适合课堂投屏。

5）透明点击层只承接进入事件，不绘制文字、图标、背景、边框、阴影或底座；可保留不可见的无障碍名称和键盘进入能力，不能将整张封面图设成透明。一次完整点击/触控只进入一次，不在 pointerdown 时提前撤掉封面；隔离本次手势，禁止继续触发下一页答案、拖拽或提交。进入第一题时仍为未作答状态。封面显示期间可预加载资源，但教学计时、题目朗读和SDK开始上报应在进入教学后沿原启动逻辑执行一次；进入封面的手势不计入作答或重试。

3. 背景图规范与生图提示词逻辑
素材分工：先识别本页答题、计数、匹配和操作目标，再将图片分为“背景”“承载物”“独立教学对象”。背景不得包含目标及容易被误认成目标的同类物、文字或操作外观；承载物只画原有容器本身，原为空的篮子、框、托盘不预装目标，也不把题目对象画进承载物；独立教学对象按原身份、数量、分组与状态保留。原任务必需的参照、干扰选项、遮挡与拼合关系仍保留，不按装饰误删。所有风格装饰候选均受此约束，材质不改变答题线索与关键几何关系；本条只约束内页，不删减第2节的封面美术。
实际调用要求：把本页目标、易混淆同类、素材角色、允许场景和应排除内容，解析成每张图片的最终生图提示词。先从第1节和本节的风格候选元素中删除冲突项，再调用生图；不得把“按任务过滤”或未填写的占位符连同被禁止物品的正向描述原样下传。页面容器或背景被重做时，重新核对全部已有教学对象仍可见、可操作。
功能控件资源边界：本次教学页功能按钮容器、图标和按钮文字由HTML/CSS/标准SVG绘制，不加入生图、图生图或图片替换清单；与题目有关的图片素材仍按原素材分工处理。
1）背景图只用于提供风格氛围，不强行生成题目承载区域。题目白板、任务板、卡片、槽位、按钮和状态栏应由 HTML/CSS/JS 根据当前课件内容绘制，并覆盖在背景图上。背景图中不要生成框、白板、题板、任务板、玻璃板、卡片、按钮、标题、题目文字、选项文字、数字、字母、汉字、格线、槽位、logo、水印或二维码。
2）背景只承担场景氛围和视觉风格统一，不承载题目、答案、玩法说明、按钮引导或知识示例。生成16:9横向全幅场景底图，场景自然延展至画面四边，仅用环境、柔和光线和配色营造主题氛围，不照搬封面构图与装饰密度。
根据当前教学布局，所有叠加题干、卡片、选项、操作对象和按钮的位置保持连续、低细节、低对比、空间由天空、墙面、地面等自然形成，不用边框、面板、卡片、独立色块或分割线划出承载区域。边缘同样保持低干扰，装饰元素少而小，仅在少数角落远景点缀；降低饱和度、对比度与细节，不用大型近景角色、道具、强光、高光、密集纹理或强透视道路吸引视线。画面不包含文字字符、色值色卡、题目答案、可能被误认为题目或选项的知识点对象、界面控件或可点物的中大主体。若主题物本身与本页答题目标冲突，省略该物，用主题配色、光照与材质维持风格。
本条只约束教学页背景；当前任务必需的参照物、真实教学对象、承载物和干扰选项按素材分工独立保留，不因背景简化删除题目内容。第1、5节列举的主题物不构成背景必画清单，和本条冲突时从实际生图提示词中移除；HTML题板按原教学布局绘制，不因背景无框而删除。

4. 核心题板、按钮、字体与触控规范
功能按钮实现（仅教学页）：返回、首页、声音/静音、重置、播放/暂停、关闭、提交、下一步等功能按钮统一使用HTML button元素、CSS标准容器和标准内联SVG图标。已有正确可用的标准SVG可复用；不生成、不替换为PNG/JPG/WebP等按钮图片，不用木牌、积木、贝壳、糖果、云朵或角色等异形外观承载功能符号，也不用emoji或依赖字体的特殊字符代替图标。此规则仅约束功能控件；题目图片、选项、字卡、拖拽块按原教学结构保留，不新增不存在的按钮或功能。
主题适配：按钮采用圆形、圆角方形或圆角矩形/胶囊形；通过主题配色、圆角、实线描边和轻微阴影体现风格，不改变标准图标的语义和比例。所有可操作功能按钮必须有独立、不透明的容器底色，图标与底色、容器与局部背景均清楚区分；默认使用暖白或白色底、深色图标和清楚描边，主题色用于主操作填充或描边。主操作用深主题色底时配高对比浅色图标和文字。不允许透明底、低透明度、木色符号融入木色背景、糖果浅色符号融入粉色背景，不能靠发光或阴影代替清楚边界。
标准图标：重置使用圆弧箭头，声音使用扬声器及声波，静音使用扬声器加斜线，播放使用右向三角，暂停使用双竖条，关闭使用叉号，返回/下一步使用方向箭头，首页使用房屋轮廓。SVG使用统一viewBox、线宽与居中规则，图形接近填满其图标位并保留适量留白；不得把极小的符号放进大SVG画布。图标不拦截父按钮输入，设置pointer-events:none；图标与按钮的文字或无障碍名称一致，声音开关图标必须反映真实静音状态。
功能按钮尺寸与适配：以下按1920×1080逻辑画布设计，舞台整体只等比缩放一次；其他逻辑分辨率按比例换算，不在已缩放父容器内再次按视口缩小。返回、首页、声音、静音、关闭：96×96px容器，SVG图标位默认64×64px；播放、暂停：112×112px容器，SVG图标位默认72×72px；重试、下一步等结果操作：宽220—280px、高88—96px，标准图标位40—48px加短文案。其他功能图标按钮容器不小于88×88px。距画布边缘不少于40px，相邻按钮间距不少于24px，均随舞台采用同一缩放比例。容器是实际点击区域，同层级尺寸、圆角、描边、图标比例统一；不能只放大透明热区。原本更大且清楚可用的按钮不为套规范强行缩小。
功能与布局保护：优先保留原有button节点、id、事件绑定、禁用态、焦点行为、计时和静音逻辑，只替换按钮内部的图片外观及CSS。原来以图片直接承接事件的控件，迁移为标准按钮时必须承接原事件，不新增按钮、不触发两次、不让图标阻挡点击。样式用功能按钮专用class，不写影响全局图片、题板和教学对象的box-sizing、padding、width或transform；教学对象的实际可见尺寸、轮廓、热区、定位和判定保持原样。空间不足先减少非教学装饰和无效留白，再调整工具区布局，不缩小教学对象、不裁切内容、不让按钮覆盖任务。
按钮验收：逐个对照原版与新版，检查实际可见SVG主体、容器、热区、相邻间距与背景区分度；在首题、弹窗、完成及重置后验证真实操作。尺寸达标但图标不清楚仍为未通过。第2节封面继续保留原完整设计图及透明进入层，封面图中的设计按钮不适用本节，禁止因本节增加第二套可见开始按钮。
尺寸指实际可点击区域，同时可见容器、图标和文字须清楚可辨，不能仅扩大透明热区而保留微小图标。按钮距离画布边缘不少于40px，相邻功能按钮间距不少于24px，均按同一比例换算。同层级按钮统一尺寸、圆角、描边和图标比例，图标居中并留白，不用夸张异形外框。
原本更大且不遮挡内容的按钮继续保留，不为套规范强行缩小。功能按钮与题目选项、教学图片、拖拽块、槽位分开处理，不能把功能按钮尺寸机械套到所有教学对象。空间不足先减非教学装饰和无效留白，再调整功能区布局，不缩小教学内容、裁切对象或让热区相互覆盖；保留原事件、禁用态、反馈和可访问名称。交付时对照换肤前后逐个核对按钮可见大小、热区、间距与实际操作。封面仍沿第2节使用完整设计图与透明进入层，不增加第二套可见按钮。
教学可读性：题干、选项文字、比较符号、数量标记和关键线条使用不透明实色，不使用透明渐变填字、浅色描边字或发光代替字形。复杂背景后为对应文字或控件加局部纯色底，不透明度不随主题降低；保留颜色作为答案线索时的原语义，不强制把所有题目改成同一颜色。玻璃、糖果和科技光效只用于学习区域之外的装饰或控件外缘，不穿过文字、线段、槽位和功能符号。
核心题板要像儿童逻辑训练工具，而不是纯背景插画。宫格、数独格、推理表、坐标格、分类框、线索区边界必须直、清楚、规整；粗分隔线和细分隔线层级明确；当前选中格可使用浅蓝底和亮蓝描边。数字、字母、图形或选项要居中、足够大、对比强，适合投屏。
数字选项按钮使用白底、轻阴影、亮蓝数字；提交按钮使用亮蓝大胶囊，带白色对勾图标和清楚文字；撤销按钮使用亮蓝或浅蓝；清除按钮可置灰并保持轮廓；提示卡使用浅绿色或浅奶油底。返回、星星、计时、关卡胶囊使用圆润图标按钮和状态胶囊。所有按钮都要有足够触碰面积、间距、按压反馈和禁用态，儿童点击不容易误触。
字体整体圆润、粗清晰、低龄友好。标题和关卡文字可更活泼；题干、规则、数字、按钮、反馈必须标准易读。不要使用过细字体、强描边、复杂阴影或装饰字。不要把文字压在蓝天背景、植物、角色或强光效上。

5. 色彩、材质与装饰密度
主色方向为明亮天空蓝、浅青蓝、奶油白、温暖黄橙、亮蓝和清新绿；辅助可用少量浅橙、浅黄、浅绿和柔和红。色彩只作为视觉方向，不在图片中显示任何色号、色卡编号、代码、CSS 文本或设计参数。整体明亮、干净、护眼，避免大面积深色、冷灰、办公蓝、强霓虹和复杂渐变。
装饰密度必须低于学习内容。纸飞机、云朵、树叶、植物、小圆点、星星和陪伴角色只放在边缘、角落或左侧辅助区，不能穿过题目、选项、槽位、宫格、按钮和反馈区域。蓝色小猫或类似陪伴角色可以作为学习助手，建议放在左侧规则区下方或题板边缘，只承担鼓励和提示氛围，不进入核心题目区。

6. UI层级与反馈
页面状态：封面只在封面状态显示并接收输入；进入教学时关闭封面容器的显示与命中，不能仅移除类名而被更高优先级的display规则重新显示。教学页使用自己的背景，不复用封面图，不继承封面的标题或开始按钮。重置沿原课件流程恢复正确页面状态；结果页和重置后再次核对封面没有透出。此规则只修显示状态，不修改第2节的封面美术内容。
底层是蓝天渐变背景；中层是大型奶油白训练营题板和内部功能卡片盖在背景图上，由html/CSS/js  绘制适合本风格的题板区域；上层是可拖拽对象、数字按钮、选项、工具按钮、提交按钮、状态胶囊和反馈卡；弹窗层用于完成、结果或时间到，必须用清楚的独立卡片承载。
正确反馈使用清新绿反馈卡、笑脸图标、星星、彩纸和“继续加油”类温和鼓励；错误反馈使用柔和红橙边框、轻微摇动和温和提示；选中态使用浅蓝填充、亮蓝描边和轻微上浮；提交成功可让星星或进度轻微点亮。所有反馈只强化原交互，不新增新玩法，不改变原题目判断逻辑。

7. 音效反馈规范
音效是 UI 反馈的一部分，必须优先匹配当前风格的专属音效；只用于强化点击、选中、拖拽、落位、提交、答对、答错、提示、完成和重置状态，不改变原课件玩法、题型、节奏和按钮功能。音效需短促、低音量、低干扰，不能循环播放，不能盖过教学语音；需遵守原课件已有静音和音量设置。若没有真实音频素材，可用平台素材库、安全音效或 WebAudio 近似实现，但仍要尽量贴近本风格音效意图。
本风格音效：点击使用清脆软按钮音，选中格子使用轻点亮声，放入或选择数字使用短促卡片落位声，提交使用明亮确认音，答对使用星星奖励铃和轻快完成音，答错使用低音量柔和提示音，不使用刺耳警报或办公系统提示音。

8. 禁止项
禁止生成真人照片、办公场景、抽象设计展板、软件界面截图、APP 字样、设计稿标题、样式说明、伪中文、伪英文、乱码、品牌名、公司名、水印、二维码、角标、色值、尺寸标记、代码或 CSS 标注。禁止把清晰逻辑风做成冷淡商务工具、纯网格背景、霓虹科技、深色竞技或复杂海报。禁止遮挡、重绘、扭曲或弱化原题目、题板、格线、槽位、按钮和反馈状态。
