0. 原课件保留规则
显示适配：保留原题目的顺序、分组、对应关系和操作流程，不把源坐标数值机械套进尺寸已改变的新题板。按实际父容器的内容宽高排布全部对象，确保末项及每个对象的完整边界都在可用区域内；空间不足时先压缩非教学装饰与间距，再局部调整卡片和题板尺寸，保持清楚可辨。拖拽位移、碰撞检测、回弹和吸附使用一致的坐标换算。不得靠裁切、隐藏对象、删减数量或让核心任务横向滚动解决越界；原教学必要的遮挡与拼合关系保留。
通用运行保护：适用于所有基础风格。保留原课件已验证的初始化、事件绑定、答案映射、教学音频、SDK上报和坐标关系，只做封面接入与视觉适配所需的局部改动；不得引入未定义变量、重复绑定、坐标错位或错误命中。除原教学需要的叠放、遮挡、拼合和连线外，不得新增使操作对象难以识别或无法命中的重叠、出界与遮挡。源课件已有阻断问题时单列原缺陷，必要修复另行记录，不通过改题或删内容掩盖。
本风格用于 UI 视觉换肤，可按第2节新增或替换封面；进入教学后不得改变原课件的学科、题型、题目内容、答案、素材数量、槽位数量、组件数量、教学布局关系、按钮功能、计分逻辑和交互流程。原来是英语看图拼词、填空、拖拽、选择、分类、连线、逻辑推理或其他玩法，换风格后仍保持原玩法和原题目结构。主互动题页中的题干、选项、答案、字母、单词、汉字、拼音、数字、公式、倒计时、得分、按钮文案、反馈文案和关卡信息等可变教学内容，必须由 HTML/CSS/JS 渲染，不要烘焙进背景图或题板底图。尤其禁止因为选择汉字启蒙风，把英语、数学或其他原课件改成语文识字题。

1. 整体视觉与布局
风格识别锚点：第一眼应像高饱和明亮的低龄汉字学习课。使用橙色、天空蓝、活力红、清新绿、温暖黄、白色大圆角内容卡片、字卡练习台、印章奖励和生活化启蒙场景；只有原课件本来是语文识字任务时，才可使用拟人汉字角色、大汉字、象形演变、听音辨字和笔画描红结构。
采用“低龄汉字认知课堂 + 字卡练习台”的 UI，而不是通用春日白板。画面第一眼应能看出是汉字启蒙学习：可使用描红纸、田字格样式空槽、偏旁积木、笔画卡、字卡收纳盒、印章奖励、毛笔或白板笔、书卷边框、课堂小桌和温和国文启蒙道具。所有这些元素只作为 UI 结构和视觉锚点，不生成随机汉字、伪字、古文、标语或无关标题。
主学习区集中在中央大号字卡练习台内。顶部承载原课件标题、关卡、进度、奖励、倒计时或得分；中央按原课件结构放置题干、图片、田字格样式槽位、偏旁/笔画/字卡素材池、选项区、连线区或分类区；底部或右侧放主要操作按钮。若原课件本来是汉字、偏旁、拼音或识字任务，推荐形成“目标字卡 + 田字格/结构槽 + 部件素材池”的清晰结构；若原课件不是语文题，只使用汉字启蒙风的纸张、字卡、印章和课堂道具，不改变原内容。

2. 封面图规范与生图提示词逻辑
【本节适用范围】第2节是完整封面设计，第3节是进入后的主互动页背景，两者必须分别生成、分别使用。封面继续执行本节第3项的原有美术描述，包括艺术字、角色、场景、材质、副标题载体和按钮设计；不得把它改成“空背景＋普通HTML标题按钮”。第3节的无文字、无按钮、中央留白要求，以及第4—6节的题板、标准正文字体、学习区低干扰规则，只约束主互动页，不得用来删减封面。选择基础风格时，默认生成或替换一张完整设计封面，源课件没有封面也默认添加；只有老师明确要求“不要封面”“直接进入题目”或“去掉封面”时才省略。不能仅凭源文件没有封面推断老师不需要。仅叠加质感时不新增封面或其他页面，保持原页面结构。

1）封面图用于儿童互动课件首页。封面图本身必须生成主标题、副标题和进入按钮；副标题不得超过15个字，图上不生成任何额外文字、包括风格名、品牌名、logo、水印、二维码、角标、色值、尺寸标记、伪文字或无关宣传语都不允许生成。封面图中的主标题、副标题、按钮造型和按钮文字是最终可见内容，必须保留。HTML 不得在这张封面图上再次叠加可见标题、副标题、按钮、按钮文字或底座；只配置覆盖封面的透明点击层，点击封面任意位置进入原课件。这里禁止的是 HTML 重复叠加，不是禁止图片生成标题或按钮。
2）主标题、副标题和按钮文案都是可变元素，必须根据当前课件真实内容替换；若为英语课件则尽量用英文，若非英语课件则一律用中文。标题、短副标题和进入按钮需要沿同一视觉主轴组织，层级清楚、可读性强，适合课堂投屏。
3）本视觉风格封面的生图提示词：
高饱和明亮的低龄汉字启蒙封面，天空蓝、草地、温暖黄、活力红和清新绿配色，儿童学习村庄、树木、小屋和彩虹。左侧可有拟人汉字角色，右侧可有小朋友、兔子学习伙伴、铅笔、字卡和田字格道具。中心上方生成圆润彩色大标题“{标题内容根据课件真实内容填充，若为英语课件则尽量用英文，若非英文课件则一律用中文}”，标题像儿童识字 App，厚白描边、带星星和铅笔装饰。标题下方生成红色或蓝色丝带副标题“{副标题内容根据课件真实内容填充，副标题不超过15个字，若为英语课件则尽量用英文，若非英文课件则一律用中文}”。中下方生成黄色或橙色圆角按钮，按钮文字为“{开始学习，按钮内容根据课件真实内容填充，若为英语课件则尽量用英文，若非英文课件则一律用中文}”，按钮带白色高光和小箭头。

4）封面接入顺序：先根据真实课件确认主标题、短副标题和进入文案，再依照上面的原版美术描述生成一张完整封面图；将它完整适配课件舞台，不裁掉文字、角色或按钮，也不把整张封面当作中间的小插图套进另一张封面。仅在封面容器内移除或隐藏源 HTML 的标题、副标题、示例插画和可见开始按钮，清理伪元素及 CSS 背景中重复的文字/按钮；主互动页的题干、选项、答案、控件和逻辑全部保留。不要因源课件原来使用 HTML 标题而继续保留第二套可见封面。
5）透明点击层只承接进入事件，不绘制文字、图标、背景、边框、阴影或底座；可保留不可见的无障碍名称和键盘进入能力，不能将整张封面图设成透明。一次完整点击/触控只进入一次，不在 pointerdown 时提前撤掉封面；隔离本次手势，禁止继续触发下一页答案、拖拽或提交。进入第一题时仍为未作答状态。封面显示期间可预加载资源，但教学计时、题目朗读和SDK开始上报应在进入教学后沿原启动逻辑执行一次；进入封面的手势不计入作答或重试。
6）交付前同时核对封面原图与浏览器实际首屏：图中艺术标题、短副标题和设计按钮齐全且各一套，浏览器没有额外的可见 DOM/CSS 文字或按钮，点击任意位置可进入第一题。若有重复，修正 HTML 接入层；若图中文字错误，单独修正封面素材。不得用删掉艺术字、角色、按钮设计，换成空场景，或直接跳过封面的办法通过去重检查。

3. 背景图规范与生图提示词逻辑
素材分工：先识别本页答题、计数、匹配和操作目标，再将图片分为“背景”“承载物”“独立教学对象”。背景不得包含目标及容易被误认成目标的同类物、文字或操作外观；承载物只画原有容器本身，原为空的篮子、框、托盘不预装目标，也不把题目对象画进承载物；独立教学对象按原身份、数量、分组与状态保留。原任务必需的参照、干扰选项、遮挡与拼合关系仍保留，不按装饰误删。所有风格装饰候选均受此约束，材质不改变答题线索与关键几何关系；本条只约束内页，不删减第2节的封面美术。
实际调用要求：把本页目标、易混淆同类、素材角色、允许场景和应排除内容，解析成每张图片的最终生图提示词。先从第1节和本节的风格候选元素中删除冲突项，再调用生图；不得把“按任务过滤”或未填写的占位符连同被禁止物品的正向描述原样下传。页面容器或背景被重做时，重新核对全部已有教学对象仍可见、可操作。
1）背景图只用于提供风格氛围，不强行生成题目承载区域。题目白板、任务板、卡片、槽位、按钮和状态栏应由 HTML/CSS/JS 根据当前课件内容绘制，并覆盖在背景图上。背景图中不要生成框、白板、题板、任务板、玻璃板、卡片、按钮、标题、题目文字、选项文字、数字、字母、汉字、格线、槽位、logo、水印或二维码。
2）背景图可以参考该风格 bg 图和 cover 图的视觉感觉自由延展，但只保留场景、色彩、材质、角色气质和边缘装饰；画面中心应保持开阔、低干扰，方便前端绘制适配当前题型的题板。
3）本视觉风格背景图的生图提示词：
任务过滤：以下场景元素均为候选装饰，须按当前页的具体目标逐项过滤；任何会与答题、计数、匹配或操作目标混淆的元素都不生成。原教学必需的参照物、干扰选项和遮挡关系仍保留。此条件优先于后面的装饰列举。
明亮低龄汉字启蒙背景，蓝天、草地、儿童学习村庄、树木、小屋、铅笔、字卡、拟人汉字角色和兔子/小朋友学习伙伴靠边放置。画面中心保持开阔、干净、低纹理，方便 HTML/CSS/JS 绘制汉字学习题板。不要生成白板框、田字格框、按钮、标题、汉字、拼音、伪汉字、logo、水印或二维码。

4. 按钮、字体与触控规范
功能图标验收：只针对独立的播放、重置等功能图标位，按图片实际可见符号检查，透明留白、外框与阴影不计入主体。核心符号最长边占图标位短边的60%—80%，使用不透明、与底色清楚区分的实色；不能只扩大外框或图片CSS盒子。优先安全去除原功能图标的无意义留白；无法安全处理时，使用语义一致的清楚符号替换其外观，保留原事件、静音逻辑和热区。完整教学图片仅按比例适配，不为凑占比裁切对象；独立小图标位规则不得套用于题目插图。
教学可读性：题干、选项文字、比较符号、数量标记和关键线条使用不透明实色，不使用透明渐变填字、浅色描边字或发光代替字形。复杂背景后为对应文字或控件加局部纯色底，不透明度不随主题降低；保留颜色作为答案线索时的原语义，不强制把所有题目改成同一颜色。玻璃、糖果和科技光效只用于学习区域之外的装饰或控件外缘，不穿过文字、线段、槽位和功能符号。
按钮使用印章按钮、纸艺胶囊按钮、字卡按钮和温暖圆角确认按钮。开始、下一题、提交、重置等按钮保持原功能，不因为汉字风格新增描红、朗读或笔顺教学玩法。
汉字、偏旁、拼音和笔画内容必须使用标准清晰字形，适合课堂投屏；汉字学习内容可使用清楚楷体、宋体或教学黑体，但不能装饰化变形。英语字母、单词、数学数字或其他学科内容跟随原课件保持标准字体。所有核心文字、字卡、选项卡、拖拽块和按钮都要触碰面积充足、间距舒适、边界清楚。

5. 色彩、材质与装饰密度
色彩以奶油宣纸白、浅米黄、朱砂红、竹青、浅木色、天空蓝、温暖黄和清新绿为主，整体明亮、温润、启蒙友好。材质可用轻纸张、字卡、浅木、印章、描红纸和磨砂白板，不使用英语单词卡、随机字母、霓虹科技、糖果宇宙或过度春日绘本元素。
色彩只作为视觉方向，不在图片中显示任何色号、色卡编号、代码、CSS 文本或设计参数。装饰密度必须低于学习内容，书卷、毛笔、印章、竹叶、字卡盒和课堂道具只放边缘或卡片角落，不能穿过题目、汉字、拼音、槽位、选项、按钮和反馈区域。

6. UI层级与反馈
页面状态：封面只在封面状态显示并接收输入；进入教学时关闭封面容器的显示与命中，不能仅移除类名而被更高优先级的display规则重新显示。教学页使用自己的背景，不复用封面图，不继承封面的标题或开始按钮。重置沿原课件流程恢复正确页面状态；结果页和重置后再次核对封面没有透出。此规则只修显示状态，不修改第2节的封面美术内容。
底层是温润国文启蒙课堂或学习桌背景；中层是中央字卡练习台和内部纸面功能卡，盖在背景图上，由html/CSS/JS 绘制适合本风格的题板区域；上层是偏旁块、笔画卡、选项、按钮、反馈条和当前选中态；弹窗层用于结果、时间到或完成反馈，必须有遮罩或清楚独立卡片。
正确反馈使用浅绿描边、印章盖章、小星光或字卡轻弹；错误反馈使用柔和红橙边框和轻微回弹；选中态使用朱砂红或温暖黄描边；拖拽落位使用田字格或字卡槽轻亮。所有反馈只强化原交互，不新增新玩法，不改变原题目判断逻辑。

7. 音效反馈规范
音效是 UI 反馈的一部分，必须优先匹配当前风格的专属音效；只用于强化点击、选中、拖拽、落位、提交、答对、答错、提示、完成和重置状态，不改变原课件玩法、题型、节奏和按钮功能。音效需短促、低音量、低干扰，不能循环播放，不能盖过教学语音；需遵守原课件已有静音和音量设置。若没有真实音频素材，可用平台素材库、安全音效或 WebAudio 近似实现，但仍要尽量贴近本风格音效意图。
本风格音效：点击使用白板笔或木质字卡轻点声，拖拽落位使用纸卡吸附声，答对使用轻印章和星星奖励音，答错使用柔和纸卡回弹声，不能新增与原学科冲突的朗读音。

8. 禁止项
禁止生成无关实体、无关玩法、无关学科内容、伪文字、乱码、伪汉字、书页假字、随机英文、品牌名、公司名、水印、二维码、角标、设计参数、色值、代码、CSS 标注、软件界面说明、宣传语和不可编辑的题目内容。禁止遮挡、重绘、扭曲或弱化原题目、题板、格线、槽位、按钮和反馈状态。尤其禁止把英语启蒙风的单词卡、随机字母、听音拼写 UI 误混入汉字启蒙风。
