# 主按钮前景色修复｜开发交付

本包在2026-11-16完整复核的9份提示词和2026-11-17核验的线上CSS基础上增量修改。没有重新拼装历史版本。尚未部署CDN或更新服务端提示词。

## 需要开发更新

1. 先将 `css/standard-icon.css` 更新到测试环境实际引用地址：`https://oss-xlss.xdf.cn/ig-kpm/resources/standard-icon.css`。该地址可能被线上课件共用，请先使用隔离地址验收，再按发布流程替换并刷新缓存；不要直接以为它是测试专用CDN。
2. 应用 `complete-prompts.zip` 的9份完整TXT，按原角色对应导入；6份变化、3份逐字保留。修改只涉及主按钮前景色，不改变输出契约。先用真实模板引擎解析，确认变量齐全。
3. 重新生成或修改浅色主按钮课件，确认深色文字与箭头一致、默认深色主按钮仍为白字、普通/禁用按钮不回退。

`icon-css-2.2.3.zip` 是独立组件包。运行时只需CSS：SVG已内嵌；manifest.json与svg目录供开发核对维护，不需要上传为运行依赖。不要用本说明或评审记录代替TXT导入。

## 唯一组件样式变化

`.cb-primary` 的 `color: white` 改为 `color: var(--cb-primary-ink, #fff)`。未指定新变量时仍显示白色；该变量可以放在实际按钮容器或目标按钮上。图标继承文字色，24个图标定义、普通按钮、选中及禁用规则不改。

浅蓝按钮示例：

```css
.cb-lightblue {
  --cb-accent: #87CEFA;
  --cb-primary-ink: #333333;
}
```

代码示例仅在开发说明，未加入系统提示词，不新增模板花括号。CSS无需对花括号额外转义。

若课件本地样式另有更高优先级的固定 `color:#fff`，需在该课件任务允许范围内删除或改为读取变量，否则仅换公共CSS仍不会生效。

## 六份提示词的最小同步

- 创建架构师、修改架构师：规划使用主按钮时同时给出前景色，浅底深字、深底浅字。
- 创建代码生成、修改代码生成：使用 `--cb-primary-ink`，不得固定白色覆盖变量；修改底色时同步核对文字和图标。
- 创建代码审查、修改代码审查：核对实际颜色，去掉“主操作必须白色”的假定。
- 方案设计、创建代码修复、修改代码修复：保持原文；修复环节已有按任务修正颜色规则，无需重复添加。

完整差异见 `改动对比.diff`。所有调试原因只留在本说明中，不写进模型提示词。

## 历史课件影响

替换共享CDN会影响引用该URL的旧课件，但未设置新变量时主按钮保持原白色，正常使用无需批量修改历史HTML。已内置CSS的旧课件不会自动更新。已有浅底白字课件仍需补上新变量；本次仅提供本地数学验证副本，原测试课件和线上历史课件未覆盖。若旧课件原本已使用同名自定义变量，其主按钮会开始读取该变量，发布前可按现有资源扫描核对。
