# 按钮文案分场景确认版

基线：`20261113-系统提示词测试环境确认版-字体随包`，在此完整九份TXT基础上仅调整本次按钮文案与多余完成入口规则。不是把Retry全局替换成Try again。当前为候选包，尚未部署或回归。

- 单题或当前步骤重试：**Retry**，只重试当前题/步骤。
- 最终结果弹窗整轮重玩：**Try again**，从第一题开始新一轮，重置本轮进度与成绩。
- 已展示完成结果时，不再添加多余的**Done/完成确认按钮**；有实际用途的继续、关闭、返回等按原需求保留。
- 中文课件使用对应中文文案。用户明确指定的文案、动作优先。

原方案设计明确推荐Retry和Done，此处已去掉Done推荐，并按上述两个范围写清Retry/Try again；架构任务传递实际文案及动作，代码生成实现，审查和修复核对。修改链路只在本轮涉及的范围内应用，不全局替换、不顺带改作答或计分逻辑。
