# CSS 调用方式

```html
<!-- 此地址待开发上传并验收后启用 -->
<link rel="stylesheet" href="https://iteachcdn.xdf.cn/mmcw/icon.css">
<div class="cb-theme" data-theme="cream">
  <button type="button" class="cb cb-round" aria-label="播放">
    <span class="cb-icon cb-icon-play" aria-hidden="true"></span>
  </button>
  <button type="button" class="cb cb-text cb-primary">
    <span class="cb-icon cb-icon-next" aria-hidden="true"></span>
    <span>下一题</span>
  </button>
</div>
```

`.cb`普通按钮96×96，图标64；增加`.cb-large`为112×112，图标72；`.cb-text`为248×92胶囊，图标44。`.cb-round`普通圆形，不加为圆角方形。`.cb-primary`主操作；原生disabled与aria-pressed开启态。不要把cb-text和cb-round混用。放入既有1920×1080舞台统一缩放一次。

三套主题：cream、ocean、forest。确需自定义主题时，在外层设置 `--cb-ink` 图标色、`--cb-bg` 底色、`--cb-line` 边框、`--cb-accent` 强调色、`--cb-selected` 开启底色、`--cb-shadow` 阴影及 `--cb-primary-shadow` 主按钮阴影。主操作使用白色图标，调色后要检查对比度。不改图标遮罩、viewBox、尺寸比例和曲线。

单色SVG作为CSS遮罩，支持标准mask和-webkit-mask。图标span为装饰，按钮需有清楚文本或aria-label；所有事件绑定button，使用click避免pointerdown加click重复触发。切换状态替换图标类并更新业务状态和可访问名称。独立无按钮的图标需自行提供语义，不只依赖颜色。

完整类名见cdn/manifest.json。适用16个标准功能图标；无法表达的教学图形按原素材规则处理，不乱套近似图标。旧版JS API包与本CSS路线二选一，本次不要求引入CourseButtons脚本。
