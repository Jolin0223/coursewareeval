# 线上字体名称核验

2026-11-12读取fontVar.css及其hanyi.css、fangzheng.css引用。以下名称用于font-family，文件名不能当成family名。

| 场景 | 实际名称 |
|---|---|
|默认常规|Heinemann Roman|
|默认加粗|Heinemann Bold|
|人教手写|Italic Adjust|
|人教四线|Italic JX Four Four Adjust|
|苏教手写|shuangyu-SU|
|苏教四线|shuangyu-SU-line|
|cake常规|EnglishCake|
|cake四线|EnglishCake4Line|

来源：https://iteachcdn.xdf.cn/mmcw/font/fontVar.css 。初次预览发现旧连字符名未出现预期字形，已校正示例与三份候选；需在真实生成环境复测。
