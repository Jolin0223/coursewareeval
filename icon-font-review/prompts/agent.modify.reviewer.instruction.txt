## Checklist
- `<meta name="viewport" … user-scalable=no>` present
-  `html, body` have `overflow: hidden` and full `width/height`
- `#app` is exactly `1920px × 1080px`, `position: absolute`, centered via `top:50\%; left:50\%`
- `transform-origin: center center` on `#app`
- `updateScale()` IIFE present, called on load and on `resize`
- No internal layout uses `vw`/`vh`
- 检查初始状态及页面切换：非当前页面、隐藏弹层及其子元素不得显示或拦截操作，专用样式不得覆盖隐藏规则。
- 沿实际HTML引用检查修改是否生效，未加载脚本不算完成；用户要求删除的功能不得被旧脚本重新创建。

## 交互约束
检查所有点击、触摸、拖拽、滑动、长按等交互时，尽量统一使用 Pointer Events：
  - 优先使用 pointerdown、pointermove、pointerup 和 pointercancel
  - 避免使用 click、mousedown、mousemove、mouseup、touchstart、touchmove 和 touchend
  - 拖拽需移动DOM时，先完成移动再设置指针捕获；正常释放才提交落点，取消、异常丢失捕获和失焦只回退与清理。结束清理须幂等，先标记结束再释放捕获，避免重复落子或残留拖拽状态。
  - 对图片等浏览器默认可拖拽的元素实现自定义拖拽时，必须关闭原生拖拽，优先设置 draggable="false"，避免桌面 Chrome 的原生图片拖放中断 Pointer Events
  - 根据需要通过 pointerType 区分 mouse、touch 和 pen
  - 拖拽时记录当前 pointerId，只处理对应指针；对于 mouse，当 buttons === 0 时必须立即停止拖拽，同时处理 lostpointercapture 和窗口失焦，避免松开鼠标后元素仍然跟随
  - 正确处理多点触控、指针移出元素、组件卸载和 pointercancel
  - 防止同一次操作被重复触发
  - 及时移除事件监听器并清理交互状态
  - 根据交互需求合理设置 CSS touch-action
  - 仅在确有必要时调用 preventDefault()

## 常用按钮与字体核验
本次涉及常用功能按钮时，先按任务区分CSS复用、同风格新增SVG或生图素材，不因采用后两种方式直接判错。复用时核对`https://iteachcdn.xdf.cn/mmcw/icon.css`或对应本地资源及类名；新增SVG核对功能语义、轮廓与整套一致性；生图核对单图主体、透明背景、无无关文字/表情/品牌水印、实际尺寸可辨识、必要状态素材齐全及无重复底座。共同核对主题对比、热区与单次舞台缩放；检查真实动作、状态同步、禁用及键盘操作，不能只换图标而没有业务效果。本次涉及字体时，按用户指定系列及四线三格要求核对font-family与资源加载，防止系统字体回退。低幼设计不应遮挡内容或破坏现有学科字体。只报告实际检查结果，不把未执行的运行验证写为通过。

核对自定义主题是否在实际按钮容器设置颜色变量，不能只凭未知data-theme名称判定配色已实现；检查主操作白色文字与底色对比、按钮实际字体。平台明确提供的图标与字体资源不作为违规第三方库报告。
